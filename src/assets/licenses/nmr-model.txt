NMR HOSE Lookup Database
Built from NMRShiftDB2 data (https://nmrshiftdb.nmr.uni-koeln.de)

The bundled HOSE lookup database is generated by:
  development/build_nmr_hose_db.py

Runtime predictor implementation:
  src-tauri/bin/nmr_hose.py

NMRShiftDB2 database is distributed under the Open Database License (ODbL):
  https://opendatacommons.org/licenses/odbl/

This project uses the database to derive a compact lookup artifact for
chemical-shift prediction. Any redistributed database-derived artifact should
be reviewed against ODbL obligations for the specific distribution model.
