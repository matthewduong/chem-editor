# CDXML reference

The CDXML DTD and the CDXML property table from Revvity's open-sourced ChemDraw CDX library
(github.com/Glysade/chemdraw, tag v1.0.12, the version RDKit's ChemDraw reader pins), under the
BSD 3-clause licence in `license.txt`. They are the "CDXML DTD" source `CLAUDE.md` asks claims
about the format to cite: attribute names, enumerated values and defaults.

They say what can be written, not how ChemDraw draws it; for that, measure (`chemdraw-fidelity.md`).
