| `<group>` containers were flattened on export                                             | **fixed 2026-10-12**                                                                   | `ChemDrawGroup` (`childIds: string[]`) already existed in the document model and in-app group/ungroup commands already built it — the only missing piece was the CDXML reader/writer: `objects` never had a `type === 'group'` writer branch (silently dropped), and the top-level `<group>` reader branch only warned and preserved raw XML, never modeling it.
